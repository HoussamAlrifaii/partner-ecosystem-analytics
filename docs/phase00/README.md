# Phase 00 research and metric contracts

Read ../../research/JOB_REQUIREMENTS.md for source evidence and ../METRIC_CONTRACTS.md for decisions. The separately maintained runbook describes the phased delivery. There is no executable application code in this research phase.

## What recruiters will actually ask

**Why this project?** My partner-distribution exposure helps me frame realistic decisions. The project then proves SQL, Python preparation, BI modeling and business communication with transparent synthetic inputs.

**Does the job sample prove the most demanded skills?** No. Seven accessible UAE/Lebanon descriptions provide directional evidence, including required, optional and alternative skills. I do not generalize those counts to the whole market.

**What is the metric grain?** One latest opportunity. Closed metrics use close date; current pipeline uses the fixed snapshot date. Those rules are written before visualization.
